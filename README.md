# Presswork

Applies the Presswork print-inspired design system to Obsidian — stamp badges from frontmatter, callout-to-component conversion, dropcap rendering, and editor insert commands.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/presswork/`, then enable the plugin in Obsidian.

## Source

This repository contains the installed JavaScript plugin. The original TypeScript source is not available in the vault.
